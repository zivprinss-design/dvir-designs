# DVIR DESIGNS · אתר מתעדכן

מבוסס ישירות על עיצוב וקבצים שהתקבלו ב־v10 (272 מוצרים עם תמונות מקומיות). **לא נבנה מחדש**: האתר המקורי, הסל והעיצוב נשמרו. כל תוכן המוצרים עבר לקובץ נתונים נפרד ויכול להישלף ממסד נתונים בענן.

## מה כבר עובד

- הגרסה המעודכנת **לא כוללת** את דפי/קישורי "אודות" ו"צור קשר", לבקשתך.

- אתר ציבורי עם עמוד בית, 3 קטגוריות, חיפוש, מידות וסל לשיתוף.
- 272 המוצרים ו־272 התמונות נמצאים בתיקיית `assets` וב־`products.json` לצורך תצוגת פתיחה.
- `/admin.html` ממשק ניהול מאובטח להוספת מוצרים, שינוי מחירים, מלאי, מידות, תמונות והסתרה.
- אחרי חיבור Supabase, האתר טוען נתונים משותפים מעודכנים ממסד הנתונים. הוא מרענן אותם אחרי חזרה ללשונית ובכל 60 שניות.
- העלאת עדכוני קוד ל־GitHub יכולה לפרסם את האתר מחדש אוטומטית באמצעות Vercel.

## חיבור למסד הנתונים (נדרש לניהול מוצרים חי)

1. צור פרויקט Supabase ושמור את כתובת הפרויקט ואת `anon/public key` (לעולם לא את `service_role`).
2. ב־Supabase > SQL Editor, הרץ פעם אחת את `schema.sql`, ולאחר מכן את `seed-products.sql` כדי לייבא את 272 המוצרים. **המלאי והמחירים המועתקים מה־v10 לא אומתו בעסק**. לא להפעיל תשלום עד שיאומתו.
3. ב־Supabase Authentication > Users צור משתמש מנהל אמיתי עם כתובת האימייל שלך וסיסמה חזקה. SQL Editor: `insert into public.dvir_admins(user_id) select id from auth.users where email='YOUR-REAL-EMAIL';` (החלף כתובת).
4. ערוך `config.js` ומלא `supabaseUrl` ואת `supabaseAnonKey` הציבוריים. את הסיסמה **לא** כותבים בקוד ולא ב־GitHub.
5. פרסם את התיקייה ב־GitHub ותן ל־Vercel להציג אותה באתר. `/admin.html` מיועד למנהל בלבד. משתמש אחר לא יוכל לערוך מוצרים גם אם יגיע לדף — בסיס הנתונים אוכף הרשאות.

שים לב: בלי הגדרת מסד הנתונים, האתר עדיין מציג את הקטלוג המקורי במצב תצוגה בלבד. האתר הציבורי **לא** מקבל הרשאות כתיבה.

## פרסום

העלה **את התוכן של התיקייה**, ולא רק את קובץ ה־ZIP, למאגר GitHub. חשוב להעלות את `assets/` עם כל תמונות המוצרים. אחר כך קשר את מאגר GitHub ל־Vercel בפרויקט Framework = Other / static, עם תיקיית root כברירת מחדל. Vercel מספק כתובת `*.vercel.app` בעלת HTTPS. בכל commit חדש יתבצע פרסום של קוד האתר.

## תשלום וניהול מלאי

הגרסה הזאת **לא גובה כסף**: סיום הסל יוצר קישור לשיתוף ולא תשלום. מסד הנתונים מציג מלאי משותף, ומנהל יכול לתקן אותו מיד. כדי להוריד מלאי **אוטומטית לאחר רכישה ששולמה**, יש לחבר ספק סליקה, לכתוב Webhook מאומת בצד השרת ולבצע הפחתת מלאי אטומית עם מניעת הזמנות כפולות. אין להפחית מלאי רק בלחיצה בצד הלקוח — זה חשוף למניפולציות.

## קבצים עיקריים

`index.html`, `style.css`, `app.js` – אתר קיים. `products.json` – קטלוג מקורי. `config.js` – הגדרות ציבוריות. `admin.html` ו־`admin.js` – ממשק ניהול. `schema.sql` – הרשאות וטבלאות. `seed-products.sql` – ייבוא מוצרים, להרצה **פעם אחת בלבד** (הרצה חוזרת עלולה לדרוס שינויים שנעשו במנהל).


## התאמה לטלפון

גרסה זו כוללת פריסה ייעודית למסכי טלפון (320–700 פיקסלים), ושומרת על צבעי שמנת/ורוד, טיפוגרפיה ותמונות המקור. דף הבית מציג את הקטגוריות זו מתחת לזו, הקטלוג מוצג בשתי עמודות, פילטרים נגללים בתוך השורה, הסל מותאם לרוחב הטלפון, ועמוד admin.html תומך בעריכה בנייד. כל השינויים הם בשכבת העיצוב בלבד ואינם מחייבים פרסום מחדש לאחר עריכת נתוני המוצרים ב־Supabase.
